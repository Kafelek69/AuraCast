# 🤝 Jak współtworzyć AuraCast?

Projekt jest otwarty i w 100% napędzany przez społeczność! Bardzo cieszymy się z każdej pomocy – od poprawy literówek po pisanie skomplikowanych modułów wideo.

## 🛠️ Podstawowy Flow (Git)

1. **Sforkuj** to repozytorium na swoje konto GitHub.
2. Sklonuj forka na swój komputer: `git clone https://github.com/TWOJ_NICK/AuraCast.git`
3. **Utwórz gałąź (branch)** dla nowej funkcji lub poprawki: 
   ```bash
   git checkout -b feature/dodanie-nowych-emotek
   ```
   *(Używaj prefixów `feature/`, `bugfix/`, `docs/`)*.
4. **Napisz kod** i upewnij się, że projekt buduje się bez błędów.
5. **Zrób commit** (staraj się jasno opisywać zmiany): 
   ```bash
   git commit -m 'feat: Dodano system nowych emotek na czacie'
   ```
6. **Wypchnij zmiany** na swój fork: 
   ```bash
   git push origin feature/dodanie-nowych-emotek
   ```
7. Przejdź na GitHuba i otwórz **Pull Request (PR)** do naszego głównego repozytorium (branch `main`).

## 🐞 Zgłaszanie błędów (Issues)
Znalazłeś buga? Masz pomysł na nową funkcję? Otwórz nowe Issue w zakładce **Issues**, zanim zaczniesz pisać kod. Opisz dokładnie problem lub swoją propozycję.
